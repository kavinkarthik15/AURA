# AURA Database Architecture v1

## Core Entities

1. Users
2. Goals
3. Tasks
4. Projects
5. Memories
6. User States
7. Experiences
8. Knowledge Assets

## Purpose

The database is designed around the concept of state-transition intelligence.

The central entity is the Experience, which records how user actions transform user states over time.

This experience data will eventually power AURA's prediction, planning, recommendation, and digital twin systems.
